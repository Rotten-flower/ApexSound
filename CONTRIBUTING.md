# Contributing / 贡献

Keep patches focused and identify the affected Minecraft / loader version. Use short role-based class names, and Chinese-first bilingual comments for non-obvious constraints. Build the affected module and test changed behavior; update corresponding descriptions and translations. Keep client-only classes out of dedicated-server initialization.

Do not submit credentials, user worlds, local AI instructions, task outputs, caches, personal paths or unlicensed assets. Describe source and rights separately for asset contributions. Code and documentation contributions use MIT; artwork and third-party material retain separate terms.

修改围绕具体问题，写明 MC 与加载器版本，验证受影响行为并同步文案。自有代码及文档贡献按 MIT；素材必须另列来源与许可，不提交本地自用资料或无授权资源。构建入口见 BUILDING.md。
